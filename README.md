# Muscle Culture Website

Version 1 concept website for **Muscle Culture — Bodybuilding Club**, a planned premium 24/7 bodybuilding gym in Lincoln, Nebraska.

## Current V1
- Responsive dark industrial black/red visual system
- Hero and brand positioning
- Equipment overview
- Founding 100 section
- Progress/body-scan concept
- Muscle Culture Athletes / Competitor Wall concept
- Waitlist UI (demo only — no backend yet)

## Next
Replace placeholders with approved logo and original photography, refine membership terms, connect waitlist storage/email, add equipment catalog, membership pages, and gym-management integration.

This site is an original Muscle Culture design. Other fitness sites may be used as general UX inspiration; their copy, imagery, and proprietary design assets are not copied.
